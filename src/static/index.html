Exocore Gemini API

Cookie-based proxy to Google Gemini — multi-turn chat, file uploads, and session management over a simple HTTP interface.

Base URL
Getting Started

Quick Start

Three steps to your first Gemini reply.

1
Check the server
Call GET /api/gemini/health — you should see client_ready: true.
2
Paste fresh cookies
Copy your Gemini session cookies from DevTools → Application → Cookies, then send them to POST /api/gemini/cookies.
3
Send a message
Call GET /api/gemini/chat?ask=Hello. Save the cid + rid from the response for multi-turn chat.
Authentication

Cookie-Based Auth

No API key needed. The server authenticates to Google using browser cookies you provide.

⚠️
Cookies expire. If you get a 401, re-paste fresh cookies via POST /api/gemini/cookies.
ℹ️
How to copy cookies: Open gemini.google.com → DevTools (F12) → Application → Cookies → select all, or use a browser extension like Cookie Editor to export as "Header String".
Endpoints

API Reference

All endpoints are prefixed with /api/gemini. Use the Try it tab to run requests live.

GET /api/gemini/health Server & client status ▶
Docs
▶ Try it

Returns the server health, Gemini client state, cookie validity, and active providers. Use this to confirm everything is working before sending chat requests.

cURL
curl "http://localhost:3000/api/gemini/health"
Response · 200 OK
{
  "ok": true,
  "data": {
    "status":        "ok",
    "client_ready":  true,
    "cookies_valid": true,
    "cookies_path":  "./exocoreCookies.json",
    "jar_size":      27,
    "providers":     ["gemini"]
  }
}
GET /api/gemini/cookies Inspect loaded cookies ▶
Docs
▶ Try it

Returns metadata about the currently loaded cookie jar. Does not expose cookie values — only count, path, and validity.

cURL
curl "http://localhost:3000/api/gemini/cookies"
Response · 200 OK
{
  "ok": true,
  "data": {
    "valid":    true,
    "path":     "./exocoreCookies.json",
    "jar_size": 27
  }
}
POST /api/gemini/cookies Upload fresh cookies ▶
Docs
▶ Try it

Replace the cookie jar with a fresh raw cookie string from your browser. The server parses, saves to disk, resets, and re-initializes the Gemini client automatically.

FieldTypeRequiredDescription
body string Required Raw cookie string SID=x; HSID=y; ... — plain text or JSON {"raw":"..."}
cURL · plain text
curl -X POST "http://localhost:3000/api/gemini/cookies" \
  -H "Content-Type: text/plain" \
  --data-raw "SID=abc; HSID=xyz; SSID=foo; ..."
Response · 200 OK
{ "ok": true, "data": { "ok": true, "parsed": 27 } }
200Cookies parsed, saved, client reset.
400Body empty or cookie string invalid.
DELETE /api/gemini/cookies Clear all cookies ▶
Docs
▶ Try it

Deletes the cookie file from disk, resets the in-memory jar, and tears down the active client. The server becomes unauthenticated until new cookies are provided.

cURL
curl -X DELETE "http://localhost:3000/api/gemini/cookies"
Response · 200 OK
{ "ok": true, "data": { "cleared": true } }
⚠️
This will delete all stored cookies and disconnect the client.
GET /api/gemini/chat?ask=<message> Send a message to Gemini ▶
Docs
▶ Try it

Sends a text prompt (and optional file URLs) to Gemini and returns the reply. Supports multi-turn conversations — pass back the cid, rid, and rcid from a previous response to continue the conversation.

ParameterTypeRequiredDescription
ask string Required* Text prompt. Alias: chat. At least one of ask or upload required.
upload string Optional Comma/space-separated file URLs to attach (images, PDFs, text).
cid string Optional Conversation ID from previous response — enables multi-turn.
rid string Optional Response ID from previous response.
rcid string Optional Response candidate ID from previous response.
cURL · simple
curl "http://localhost:3000/api/gemini/chat?ask=What+is+the+capital+of+France"
cURL · multi-turn
# First turn
curl "http://localhost:3000/api/gemini/chat?ask=Tell+me+a+joke"

# Continue the conversation with cid/rid from above
curl "http://localhost:3000/api/gemini/chat?ask=Explain+it&cid=CID&rid=RID&rcid=RCID"
JavaScript · fetch
const res  = await fetch(`/api/gemini/chat?ask=${encodeURIComponent('Hello!')}`);
const { msg, cid, rid, rcid } = await res.json();
console.log(msg); // Gemini reply
Response · 200 OK
{
  "msg":  "Paris is the capital of France.",
  "cid":  "c_abc123",
  "rid":  "r_xyz789",
  "rcid": "rc_000"
}
200msg = AI reply. Save cid/rid/rcid for follow-up turns.
400No ask param and no valid upload URL.
401Cookies missing or expired — re-authenticate.
500/503Gemini client error or unexpected failure.
Multi-turn IDs (optional)
